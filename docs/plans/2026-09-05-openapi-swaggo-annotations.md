# Task 029: Add swaggo Annotations + OpenAPI Spec Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Annotate all Go HTTP handler functions and `main.go` with `swaggo/swag` declarative comments, generate OpenAPI specifications (`swagger.json`, `swagger.yaml`, `docs.go`) into `backend/specs/`, adapt `scripts/generate_fe_types.bash` to convert Swagger 2.0 to OpenAPI 3.0 via `swagger2openapi` and produce verified TypeScript types in `frontend/src/types/types.generated.ts`, ensure clean compilation and zero lint errors, and mark task 029 as completed.

**Architecture:**
- `backend/cmd/arch-stats/main.go`: Declares top-level General API Info annotations (`@title`, `@version`, `@description`, `@BasePath /api/v0`, and `@securityDefinitions.apikey BearerAuth`).
- `backend/internal/model/`: Adds backward-compatible type aliases (`GenderType = Gender`, `BowStyleType = Bowstyle`, `SessionId = SessionID`, `ShotId = ShotID`) and validation error shapes (`HTTPValidationError`, `ValidationError`) so generated OpenAPI schemas precisely match frontend TypeScript expectations.
- `backend/internal/handler/`: Decorates every handler function across `auth.go`, `archer.go`, `session.go`, `slot.go`, `shot.go`, `face.go`, `live_stats.go`, and `health.go` with comprehensive swaggo annotations (`@Summary`, `@Description`, `@Tags`, `@Accept`, `@Produce`, `@Param`, `@Success`, `@Failure`, `@Security`, `@Router`).
- `backend/specs/`: Target output directory generated by `swag init -g cmd/arch-stats/main.go -o specs/ --parseInternal --useStructName`.
- `scripts/generate_fe_types.bash`: Updated to detect and convert `backend/specs/swagger.json` to OpenAPI 3.0 using `npx swagger2openapi -p` before running `npx openapi-typescript`, ensuring seamless frontend type generation.
- `docs/go_refactor/tasks/029-openapi_swaggo_annotations.md` & `docs/plans/task.md`: Marked as completed upon full verification.

**Tech Stack:** Go 1.27, `github.com/swaggo/swag/cmd/swag` (v1.16.4+), `swagger2openapi`, `openapi-typescript` (v7.13.0), Vue 3 + TypeScript (`vue-tsc`), `golangci-lint`.

- [ ] **Step 4: Update `scripts/generate_fe_types.bash` to convert Swagger 2.0 to OpenAPI 3.0**

Update `scripts/generate_fe_types.bash` so that if `backend/specs/swagger.json` exists or is specified, it uses `npx swagger2openapi` to produce an OpenAPI 3.0 `openapi.json`:

```bash
#!/usr/bin/env bash

set -euo pipefail

ROOT_DIR="$(cd "$(dirname "$(readlink -f "${BASH_SOURCE[0]}")")/.." && pwd)"
ENV_FILE="${ROOT_DIR}/.env"

convert_swagger_to_openapi() {
    local src="$1"
    local dst="$2"
    (
        cd "${ROOT_DIR}/frontend"
        echo "Info: Converting Swagger 2.0 spec (${src}) to OpenAPI 3.0 (${dst})"
        npx --yes swagger2openapi "${src}" -o "${dst}" -p
    )
}

openapi_via_script() {
    local openapi_source="$1"
    (
        cd "${ROOT_DIR}/backend-old"
        export PYTHONPATH="${ROOT_DIR}/backend-old:${ROOT_DIR}/backend-old/src"
        echo "Info: Generating OpenAPI spec from script"
        uv run ./tools/generate_openapi.py "${openapi_source}"
    )
}

frontend() {
    local openapi_source="$1"
    (
        cd "${ROOT_DIR}/frontend"
        if grep -q '"swagger":' "${openapi_source}" 2>/dev/null; then
            local v3_target="${ROOT_DIR}/openapi.json"
            convert_swagger_to_openapi "${openapi_source}" "${v3_target}"
            openapi_source="${v3_target}"
        fi
        echo "Info: Generating frontend types from ${openapi_source}"
        npx openapi-typescript "${openapi_source}" --export-type --output src/types/types.generated.ts
    )
}

main() {
    local openapi_source
    if [[ -f "${ENV_FILE}" ]]; then
        # shellcheck source=../.env
        source "${ENV_FILE}"
    fi

    openapi_source="http://localhost:${ARCH_STATS_SERVER_PORT:-8000}/api/openapi.json"
    if ! curl --silent --fail --head "${openapi_source}" >/dev/null 2>&1; then
        if [[ -f "${ROOT_DIR}/backend/specs/swagger.json" ]]; then
            openapi_source="${ROOT_DIR}/openapi.json"
            convert_swagger_to_openapi "${ROOT_DIR}/backend/specs/swagger.json" "${openapi_source}"
        elif [[ -f "${ROOT_DIR}/backend-old/tools/generate_openapi.py" ]]; then
            openapi_source="${ROOT_DIR}/openapi.json"
            openapi_via_script "${openapi_source}"
        else
            openapi_source="${ROOT_DIR}/openapi.json"
        fi
    fi
    frontend "${openapi_source}"
    exit 0
}

main
```
